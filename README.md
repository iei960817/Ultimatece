# ULTIMATE — 极简奢华婚礼空间美学网站压缩包（V3 丝滑动画 & 手机适配 & 大图对比版）

## 本次升级亮点
1. **顺畅优雅的入场动画**：优化了纯白开场黑点过渡，取消突兀的巨大黑块闪烁，改为柔和呼吸光环扩散与主页面渐显上浮。
2. **完整手机端响应式适配**：顶部导航自动适配手机触控区域、单列作品卡片、2×2 地毯尺寸快捷键、全站安全区（Safe Area）兼容。
3. **大图全屏对比模式**：每张作品卡片右下角新增 **「⤢ 放大对比」** 按钮，点击后弹出全屏大图，依然支持左右拖动滑杆对比 3D 概念图与实际完成品，也可在底部一键切换单图预览。

## 使用方式
1. 解压后双击 `index.html` 即可在电脑或手机浏览器中打开。
2. 点击顶部 **「GitHub 后台」** 登录后，可自由替换每组作品的 **3D 概念图** 与 **实际完成品**，并编辑全站所有文字与价格。
