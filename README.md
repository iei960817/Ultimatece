# ULTIMATE — 极简奢华婚礼空间美学网站压缩包

本压缩包已为您打包可直接运行的网站模板（支持纯白黑点 `ULTIMATE` 开场动画、右上角 **作品 / 价钱 / 关于我们** 分页、**地毯简易计算器（40 / 52 / 60 / 80 ft × 无木 RM1.50 / 有木 RM4.00）**、**3D 概念图与实际完成品切换/对比**，以及 **GitHub 后台登录与全站图文实时编辑**）。

## 快速本地预览
1. 解压本压缩包到任意文件夹。
2. 双击打开 `index.html` 即可在浏览器中使用（建议使用 VS Code Live Server 或任意静态服务器打开，效果最完整）。

## 如何使用 GitHub 登录与替换 2D/3D 图与文字
1. 点击页面右上角 **「GitHub 后台」** 按钮。
2. 输入您的 **GitHub 用户名** 进入后台编辑器（若需直接推送修改到 GitHub 仓库，可一并填入仓库 `owner/repo` 与具有 `repo` 权限的 Token）。
3. 在后台中您可以：
   - **作品与 2D/3D 图替换**：上传本地图片或填入图片链接，分别设置「3D 概念图」与「实际完成品」，前台即可一键切换或拖动对比滑杆。
   - **全站文字编辑**：修改开场字样、主标题、关于我们段落、工作室联络信息、常规配套与加购项目。
   - **保存 / 导出 / 同步**：点击「保存并应用到页面」即可立即看到前台效果；也可点击「下载 site-config.json」或「推送到 GitHub」保存配置。

> **注**：纯静态网页直接做真实 GitHub OAuth 密钥交换需要后端 Server；本模板采用「GitHub 账号会话登录 + 本地持久化 + 可选 GitHub Contents API 直推 JSON」方案，解压即用，无需额外搭建后端服务器。
